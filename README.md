# E-commerce Automation Practice

This project is a Java-based QA automation repository focused on testing an e-commerce website using Selenium and JUnit 5. It includes end-to-end UI tests for product search, category browsing, cart management, and user registration, along with API-related validation examples.

## Project Overview

The repository demonstrates the Page Object Model (POM) approach for web automation and follows a clean separation between:

- page objects
- test classes
- reusable actions and assertions

## Tech Stack

- Java 17
- Maven
- Selenium WebDriver
- JUnit 5
- REST Assured
- ChromeDriver via WebDriverManager
